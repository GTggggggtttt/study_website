## 1. 贡献点分类

1. **轻量化语义边界感知分割**（DeepLabv3+ 修改）
   - MobileNetV4 backbone 替换原 Xception → 模型体积 / 推理速度数据
   - 引入 CA（Coordinate Attention）注意力 → mIoU 提升数据

2. **5 阶段语义加权 SLAM 框架**
   - Phase 1+2：特征级语义加权（PoseOpt + ORBmatcher）
   - Phase 3+4：MapPoint 长期语义统计 + BA 残差加权
   - Phase 5：解决分割不确定性(膨胀)
   - 与 baseline ORB-SLAM3、其他主流视觉SLAM做对比

3. **果园场景定制化权重设计**
   - 类基础权重 + 置信度乘子 + 时序稳定性乘子（动态权重，非静态常数表）
   - 行尾天空主导 / 电线杆类长期稳定结构感知

4. **公开与实地长时序数据集**
   - 火龙果园 / 木瓜园 / 柑橘园 ZED2i + IMU 多场景数据
   - 在 Citrus-Farm 公开数据集上的 ATE 改善
